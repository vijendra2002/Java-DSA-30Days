---

## Syntax

### if

```java
if (condition) {
    // code
}
```

### if-else

```java
if (condition) {

} else {

}
```

### else-if

```java
if (condition1) {

} else if (condition2) {

} else {

}
```

### switch

```java
switch (variable) {
    case 1:
        break;

    case 2:
        break;

    default:
        break;
}
```

## Important Interview Points

- if checks conditions one by one.
- switch works with fixed values.
- break exits the switch block.
- default executes when no case matches.
- Use if-else for ranges.
- Use switch for fixed choices.
