# Day 05 - Patterns

## Topics Covered

- Nested Loops
- Star Pattern

---

## Concepts

- Outer loop → Rows
- Inner loop → Columns

General Structure:

```java
for (int i = 1; i <= rows; i++) {
    for (int j = 1; j <= cols; j++) {

    }
}
```

---

## Important Interview Points

- Outer loop controls rows.
- Inner loop controls columns.
- Most pattern problems use nested loops.
- Dry run row by row before coding.

---

## Time Complexity

Most pattern programs → O(n²)
